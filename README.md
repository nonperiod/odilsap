# odilsap

授業中の質問や意見をリアルタイムに共有する、React と Firebase を使った授業参加支援アプリです。参加者は固定URLやQRコードからアクセスし、匿名または名前付きで投稿できます。

主な機能：

- 質問・Q&Aの投稿と共感
- 自由記述の設問、回答、コメント
- ライブ投票（単一選択・複数選択・自由記述）と集計グラフ
- 管理者による受付・公開状態の管理、開催回の切り替え
- 授業で使う投影画面
- 過去の開催回の結果閲覧、CSV・Excel・Googleスプレッドシートへの出力

Firebase 未設定時は、同じブラウザ内で動作するデモモードを利用できます。アンケート・小テスト・出席管理は未実装です。
